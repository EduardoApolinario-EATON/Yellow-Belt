# Fase 01 — Define

Esta fase formaliza o problema, o escopo, o time e as premissas do projeto. É a fundação sobre a qual as fases seguintes (Measure, Analyze, Improve, Control) se apoiam.

## Documentos desta fase

| Documento | Conteúdo |
|---|---|
| [01_Project_Charter.md](01_Project_Charter.md) | Carta do projeto — problema, objetivos SMART, indicadores, time, cronograma |
| [02_Justificativa.md](02_Justificativa.md) | Texto curto de motivação para o charter |
| [03_Escopo_e_Premissas.md](03_Escopo_e_Premissas.md) | O que entra, o que sai, restrições firmes e premissas |
| [05_Time_e_Stakeholders.md](05_Time_e_Stakeholders.md) | Papéis no projeto e interlocutores por área |

## O que esta fase responde

- Qual problema o projeto resolve?
- Qual o impacto atual do problema?
- Qual o objetivo (em métrica)?
- O que fica dentro e fora do escopo?
- Quais restrições não podem ser violadas?
- Quem participa, decide e patrocina?
